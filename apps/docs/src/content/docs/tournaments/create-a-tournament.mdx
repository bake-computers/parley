Organizers start in Discord and finish on the website, where the full setup
form lives.

<Steps>
  <Step title="Run the command in your host server">
    Run `/tournament create` in a channel of the server the tournament belongs to. It does not work
    in direct messages.
  </Step>
  <Step title="Open the secure link">
    Parley replies with a link to the creation page on [parley.bot](https://parley.bot). The link is
    signed for you and your server.
  </Step>
  <Step title="Log in and set it up">
    On the website you choose the name, format, team cap, schedule, rules, and prizes. When you
    publish, the tournament gets a ten-character code.
  </Step>
  <Step title="Share the code">
    Give players the code. They join with [/tournament join](/tournaments/join-a-tournament) from
    any server.
  </Step>
</Steps>

<Aside type="caution" title="Links expire after ten minutes">
  The hand-off link is only valid for ten minutes, and only for the user and server it was made for.
  If it lapses, run `/tournament create` again. There is no penalty for generating a new link.
</Aside>

<Aside type="tip" title="Keep the code handy">
  The code is how everyone finds your tournament. Post it in an announcements channel and pin it.
  Players can also reach the tournament page directly at parley.bot with the code.
</Aside>

Parley tournaments are organized on the [parley.bot](https://parley.bot)
website, where organizers set everything up and brackets play out. Discord
is the doorway: one command to create, one to join.

## The basics

- **Formats**: single elimination or double elimination.
- **Team size**: five a side by default, with smaller formats available.
- **Seeding**: teams are seeded by skill, so the bracket opens with the
  fairest first rounds it can make.
- **Joining**: every tournament has a six-character code that players use
  from Discord.

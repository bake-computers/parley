---
title: Join a tournament
description: Go from a share code to a spot on the roster.

  order: 2
---

Joining takes one command and a short visit to the tournament page.

<Steps>
  <Step title="Get the code">
    The organizer shares a ten-character tournament code, for example `K7QRT2WXMB`. It uses letters
    A through Z and digits 2 through 9, so nothing looks like a 0, O, or 1. Older tournaments use
    six-character codes, which still work.
  </Step>
  <Step title="Run the command">
    ```text /tournament join code: K7QRT2WXMB ``` Lowercase is fine; Parley uppercases it for you.
  </Step>
  <Step title="Open the tournament page">
    On success, Parley shows the tournament name and status with a link to its page.
  </Step>
  <Step title="Log in and pick your team">
    Log in with Discord on the tournament page and select the same team as your teammates. Roster
    and check-in happen there too.
  </Step>
</Steps>

<Aside type="tip" title="Codes are easy to misread">
  Codes are meant to be read out in voice chat. If the command says
  **Tournament not found**, read the code back character by character, or ask the organizer for the
  direct page link.
</Aside>

<Aside type="caution" title="Codes can go stale">
  A code stops resolving when its tournament is canceled or cleaned up. **Tournament not found** on
  a code that used to work means the organizer ended it; ask for a current one.
</Aside>

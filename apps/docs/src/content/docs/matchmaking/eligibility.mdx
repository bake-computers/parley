Before Parley builds teams, it checks every participant against a short list
of rules. Most are yours to control; a few belong to the server.

## Why you might be left out

| Reason | Who controls it | The fix |
| --- | --- | --- |
| Your matchmaking is disabled | You | Set matchmaking to Enabled in [/user](/commands/user) |
| Server matchmaking is off | Server admins | Ask an admin to enable matchmaking for the server |
| Daily match limit reached | Server admins | Come back tomorrow; limits reset daily |
| Your rank is outside the server's range | Server admins | Servers can gate matches to a rank band; ask what the band is |
| Your platform is not allowed | Server admins | Some servers whitelist platforms, for example PC only |
| Skill gap in the lobby is too wide | Nobody | The group spans too much skill to balance fairly; split into closer lobbies |

<Aside type="tip" title="Most blocks are one setting away">
  If you linked recently and matches just work for others, check your own
  matchmaking toggle first. It is the most common reason.
</Aside>

<Aside type="caution" title="Verification gates">
  A server can also require verified players. If you are told you are not
  verified, ask a server admin what verification means for that community.
</Aside>

`/tournament` connects Discord to the tournament dashboard on the Parley
website. Setup, registration, and brackets live there; Discord handles the
hand-off.

## /tournament create

Run it in the server that will host the tournament. Parley replies with a
secure link to the creation page on [parley.bot](https://parley.bot), where
you log in and choose the format, schedule, rules, and prizes.

<Aside type="caution" title="The link expires">
  The hand-off link is valid for ten minutes and is tied to you and the server you ran it in. If it
  expires, run the command again.
</Aside>

<Aside type="note" title="Servers only">
  Like `/history`, tournament creation needs a server channel. It does not work in direct messages.
</Aside>

## /tournament join

Takes one argument: the tournament code.

```text
/tournament join code: ABC123XYZ4
```

The code is ten characters, letters A through Z and digits 2 through 9
(tournaments created before the code length changed use six).
Lowercase input is uppercased for you. On success, Parley shows the
tournament name and status with a link to its page, where you log in with
Discord and pick your team.

<Aside type="tip" title="Tournament not found?">
  Check the code with the organizer. Codes are short on purpose and easy to misread; a wrong or
  expired code shows **Tournament not found**.
</Aside>

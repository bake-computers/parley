`/history` shows the five most recent Parley matches played in the server
you run it from. It is a quick way to see how last night went without leaving
Discord.

<Aside type="caution" title="Servers only">
  `/history` does not work in direct messages. Run it in a channel of the server whose matches you
  want to see.
</Aside>

## What you see

The card lists each match as:

- **The two teams**, with the winner in bold.
- **When it was played**, as a relative time that Discord keeps current for
  you.
- **The MVP**, when a match produced one.

If the server has no Parley matches yet, the card says so and hints that
matches will appear here once your team plays.

<Aside type="note" title="Five at a time">
  The card shows the five most recent matches and leaves out older ones.
</Aside>

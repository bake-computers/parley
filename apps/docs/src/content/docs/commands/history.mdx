`/history` shows the recent Parley matches played in the server you run it
from, one match per page. Use the **Previous** and **Next** buttons under the
card to flip through matches, newest first.

<Aside type="caution" title="Servers only">
  `/history` does not work in direct messages. Run it in a channel of the server whose matches you
  want to see.
</Aside>

## What you see

Each page shows one match as:

- **The two teams**, with the winner in bold and every player's reported
  K/D/A next to their name.
- **Rating change** per player — how the match moved their Parley rating.
  Matches reported before rating tracking show K/D/A only.
- **When it was played**, as a relative time that Discord keeps current for
  you.
- **The MVP**, when a match produced one.

If the server has no Parley matches yet, the card says so and hints that
matches will appear here once your team plays.

<Aside type="note" title="Twenty at a time">
  `/history` pages through the twenty most recent matches in the server.
</Aside>

Type `/` in any server channel to see the Parley commands. Every reply is
private to you: nobody else in the channel sees your cards or menus.

<Aside type="note" title="Replies are only visible to you">
  Parley answers in ephemeral messages. Your linked accounts, settings, and match data never appear
  in the public channel.
</Aside>

## Command reference

| Command              | What it does                                  | You need                           | Details                             |
| -------------------- | --------------------------------------------- | ---------------------------------- | ----------------------------------- |
| `/link`              | Link your Discord to your in-game account     | Terms accepted                     | [/link](/commands/link)             |
| `/profile`           | View your linked game accounts and stats      | A linked account                   | [/profile](/commands/profile)       |
| `/history`           | Show the last 5 matches played in this server | A linked account, a server channel | [/history](/commands/history)       |
| `/user`              | Manage matchmaking, visibility, and data      | A linked account                   | [/user](/commands/user)             |
| `/tournament create` | Start a tournament on the Parley website      | A server channel                   | [/tournament](/commands/tournament) |
| `/tournament join`   | Open a tournament by code                     | A tournament share code            | [/tournament](/commands/tournament) |
| `/help`              | List all available commands                   | Nothing                            |                                     |
| `/ping`              | Check if the bot is responsive                | Nothing                            |                                     |

<Badge variant="info">First run</Badge> The first time you run `/link`, `/profile`, `/history`, or
`/user`, Parley shows a one-time welcome card. Accept the terms and the command continues where you
left off. The details are in [getting started](/getting-started).

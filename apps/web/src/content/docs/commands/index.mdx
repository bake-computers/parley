Type `/` in any server channel to see Parley commands. Every reply is
**private to you** — nobody else in the channel sees your cards or menus.

<Aside type="note" title="Replies are only visible to you">
  Parley answers in ephemeral messages. Your linked accounts, settings, and match data never appear
  in the public channel.
</Aside>

## Command reference

| Command              | What it does                                  | You need                           | Guide                                    |
| -------------------- | --------------------------------------------- | ---------------------------------- | ---------------------------------------- |
| `/link`              | Link Discord to your in-game accounts         | Terms accepted                     | [/link](/docs/commands/link)             |
| `/profile`           | View linked accounts and Parley Rank          | A linked account                   | [/profile](/docs/commands/profile)       |
| `/history`           | Last matches in this server                   | Linked account, server channel     | [/history](/docs/commands/history)       |
| `/user`              | Matchmaking, visibility, data                 | A linked account                   | [/user](/docs/commands/user)             |
| `/team`              | Custom balanced match + round logging         | Server channel, 2–10 players       | [/team](/docs/commands/team)             |
| `/tournament create` | Start a tournament on the website             | Server channel                     | [/tournament](/docs/commands/tournament) |
| `/tournament join`   | Open a tournament by code                     | Tournament share code              | [/tournament](/docs/commands/tournament) |
| `/help`              | List commands                                 | Nothing                            |                                          |
| `/ping`              | Check the bot is up                           | Nothing                            |                                          |

<Badge variant="info">First run</Badge> The first time you run `/link`,
`/profile`, `/history`, or `/user`, Parley may show a one-time welcome card.
Accept the terms and the command continues. Details:
[getting started](/docs/getting-started).

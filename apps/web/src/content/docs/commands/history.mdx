`/history` pages through recent Parley matches **in the server you run it from**
— one match per page, newest first. Private to you.

<Aside type="caution" title="Servers only">
  `/history` does not work in DMs. Use a channel in the server whose matches you want to see.
</Aside>

## How to use it

<Steps>
  <Step title="Run /history in a server channel">
    Type `/history`. Parley loads up to the twenty most recent matches for that
    server.
  </Step>

  <Step title="Read a match">
    Each page is one match: both teams, K/D/A, rating changes, when it was played,
    and the MVP when there is one. The winning team is marked.

    <HistoryMatchDemo />
  </Step>

  <Step title="Flip pages">
    Use **Previous** and **Next** under the card to move through the list.
  </Step>
</Steps>

## Empty server

If nobody has played a Parley match here yet, you get a short empty state.

<HistoryEmptyDemo />

Custom `/team` matches show up here too once they are finished and ratings
are updated.

## What the numbers mean

- **K/D/A** — kills / deaths / assists logged for that player in the match.
- **(+18) / (−12)** — how the match moved their Parley rating. Older matches
  without rating tracking show K/D/A only.
- **MVP** — standout player when the match recorded one.

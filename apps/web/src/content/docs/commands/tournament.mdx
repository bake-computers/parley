`/tournament` hands you from Discord to the tournament dashboard on the
Parley website. Setup, registration, and brackets live on the site; Discord
starts the flow.

## Create a tournament

<Steps>
  <Step title="Run /tournament create in a server">
    Use a channel in the server that will host the event. Creation does **not**
    work in DMs.
  </Step>

  <Step title="Open the hand-off link">
    Parley replies with a private link to the website. Log in with Discord and
    choose format, schedule, rules, and prizes.

    <TournamentCreateDemo />
  </Step>

  <Step title="Finish on the site">
    Complete setup before the link expires. Share the tournament code or page
    with players when you are ready.
  </Step>
</Steps>

<Aside type="caution" title="The link expires">
  The hand-off is valid for **ten minutes** and is tied to you and the server you ran it in. If it
  expires, run `/tournament create` again.
</Aside>

## Join a tournament

<Steps>
  <Step title="Get the code">
    Organizers share a short code (ten characters, A–Z and 2–9; older events may
    use six). Lowercase is fine — Parley uppercases it.
  </Step>

  <Step title="Run /tournament join">
    ```text
    /tournament join code: ABC123XYZ4
    ```
  </Step>

  <Step title="Open the tournament page">
    On success you see the name, status, and a link. Log in on the site and
    pick your team.

    <TournamentJoinDemo />
  </Step>
</Steps>

<Aside type="tip" title="Tournament not found?">
  Double-check the code with the organizer. A wrong or expired code shows **Tournament not found**.
</Aside>

`/profile` shows every game account linked to your Discord, with each platform's
Parley Rank. Private reply — only you see it.

## How to use it

<Steps>
  <Step title="Run /profile">
    Type `/profile` in any channel or DM. No options needed.
  </Step>

  <Step title="Read your accounts">
    Each linked platform is a line with game, username, platform, and Parley Rank.

    <ProfileLinkedDemo />
  </Step>
</Steps>

## No accounts yet?

If nothing is linked, Parley points you at `/link`.

<ProfileEmptyDemo />

Run [/link](/docs/commands/link) once — it takes about a minute — then `/profile`
again.

## About the rank shown

Parley Rank is Parley's own skill ladder. It seeds from your Rainbow Six rank
when you link and moves when you play Parley matches. It does **not** change
your Ubisoft rank.

| Field       | Example              |
| ----------- | -------------------- |
| Game        | Rainbow Six Siege    |
| Username    | your in-game name    |
| Platform    | PC, Xbox, PlayStation |
| Parley Rank | Gold · 2,540         |

Full ladder: [Parley Rank](/docs/ranks-and-stats/parley-rank). Deeper stats
after linking: [your stats](/docs/ranks-and-stats/your-stats).

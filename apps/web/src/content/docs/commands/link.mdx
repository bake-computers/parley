`/link` opens your account hub. It takes no arguments and walks you through
everything with menus.

## The link hub

The hub lists every platform you have linked, each with its username and
Parley Rank. Two menus sit underneath:

- **Add a platform** picks a platform you have not linked yet.
- **Remove a link** unlinks one of your existing profiles.

New here? The full first-time walkthrough is on the
[link your account](/docs/getting-started/link-your-account) page.

## Remove a link

Select the profile under **Remove a link** and Parley unlinks it right away.
The hub confirms the removal and shows when you can link that platform again.

<Aside type="caution" title="Re-link cooldown">
  Removing a link starts a waiting period before that platform can be linked again. Parley shows the
  exact date and time on the hub. The cooldown exists so ratings cannot be reset by hopping between
  accounts.
</Aside>

## Errors you might see

| Card                 | What it means                                   | What to do                                      |
| -------------------- | ----------------------------------------------- | ----------------------------------------------- |
| **Link Failed**      | The stats provider could not find that username | Check spelling and platform, then try again     |
| **Re-link Cooldown** | You removed a link recently                     | Wait until the shown time, then link again      |
| **Already linked**   | That platform already has a profile             | Remove the old link first if you want to switch |

<Aside type="tip" title="One account per platform">
  You can link one Rainbow Six profile per platform: one PC, one Xbox, and one PlayStation. If a
  platform is already linked, the wizard simply returns you to the hub.
</Aside>

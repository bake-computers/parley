================================================================================
FAILURE ANALYSIS
================================================================================

1. HYDRATION MISMATCH (Critical)
   Location: /dashboard
   File: apps/web/src/routes/dashboard/index.lazy.tsx
   
   Server rendered:
     <div className="min-h-screen flex items-center justify-center">
       <Loading01Icon spinner />
   
   Client rendered:
     <div className="min-h-screen flex items-center justify-center px-4">
       <Card>Sign in with Discord...</Card>
   
   Root cause: Auth state (`isPending`, `session`) differs between SSR and client.
   The server shows a loading spinner while the client immediately shows the
   unauthenticated state. This causes React to discard and re-render the tree.

2. CONNECTION REFUSED (Environment, not UI bug)
   URLs affected:
     - http://localhost:8787/api/auth/get-session
     - http://localhost:8787/api/leaderboard?page=1&pageSize=50
     - ws://localhost:8787/ws/leaderboard
   
   These are backend API/WebSocket calls. The Cloudflare Workers dev server
   (port 8787) was not running during this QA session. No static assets (CSS,
   JS, images, fonts) returned 404.

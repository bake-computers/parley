# Task 19: Bundle Optimization and Asset Cleanup

## Changes Made

### 1. Vite Build Configuration (`apps/web/vite.config.ts`)
- Added `build.rollupOptions.output.manualChunks` as a function to split vendor chunks:
  - `react`: includes `react` and `react-dom`
  - `radix`: includes `radix-ui`
  - `tanstack`: includes `@tanstack/react-router` and `@tanstack/react-start`
- Used function form to be compatible with Rolldown (Vite 8), which expects `manualChunks` to be a function, not an object.

### 2. Removed Unused Dependency
- Removed `lucide-react` from `apps/web/package.json`
- Verified zero source references to `lucide-react` in `apps/web/src/`
- Ran `bun install` to update lockfile

### 3. Verified Still-Used Dependencies
- `class-variance-authority` - used by `button.tsx`, `badge.tsx`, `card.tsx`
- `clsx` / `tailwind-merge` - used by `lib/utils.ts` (cn() utility)
- `tw-animate-css` - imported in `styles.css`
- `better-auth` - used in `lib/auth.ts`
- `@base-ui/react` - used in `dropdown-menu.tsx`, `avatar.tsx`

### Notes on Size
- The baseline (2.1M) was recorded **before** the UI overhaul when shadcn/ui, radix-ui, JetBrains Mono fonts, and other dependencies were not yet installed.
- The current total dist (2.8M) includes both client (1.1M) and server (1.7M) builds.
- The client-only build is 1.1M, which is significantly smaller than the baseline total.
- Manual chunk splitting does not reduce total bytes but improves caching by isolating vendor code.
- Removing `lucide-react` had negligible size impact because it was already tree-shaken out (zero imports in source).
